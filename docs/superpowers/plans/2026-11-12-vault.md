# Password Vault Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox syntax.

**Goal:** Implement the approved deterministic password terminal application.
**Architecture:** One script with pure crypto functions, SQLCipher session and Textual screens. Session owns only derived generation key and database connection; closing wipes mutable key buffer.
**Tech Stack:** Python 3.10+, Textual, sqlcipher3, pyperclip, unittest.
**Spec:** docs/superpowers/specs/2026-11-12-vault-design.md

## Global Constraints
- No random generation salt; fixed v1 parameters and email canonicalization.
- Arrow/Enter/Esc navigation only; 1800-second absolute unlock lifetime.
- No plaintext database fallback, no password persistence or secret logging.

## Review Focus
- Wrong master or corrupt database must never overwrite existing data.
- Empty/invalid/duplicate emails must not create rows.
- Lock must remove account widgets and derived key, even from add dialog.
- Copy failures must not expose passwords in error messages.
- First-run confirmation and responsive minimum terminal layout.
